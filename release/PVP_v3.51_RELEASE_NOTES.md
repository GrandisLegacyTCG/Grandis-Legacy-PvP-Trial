# Grandis Legacy PvP v3.51 — Release Notes

Date: 2026-09-28

PvP **v3.51** promotes the completed v3.50 staged correction into a distinct semantic release number. The purpose of the version change is release clarity; no new gameplay rule is introduced by the promotion itself.

Retained final behavior includes server-authoritative render continuity, mobile Draw presentation, nested Response/held-card lifecycle, battle VFX/SFX delivery, custom Main Deck legality **50–60 inclusive**, 25-character visible deck-name presentation, and the external aligned Connection Bar. Official Starter Decks remain 60 cards.

Website mirror target: **v1.40**.

## Same-version minor correction — 2026-09-28

- Hero EXP cards now keep identical physical scale in Ready and Exhausted presentation; only orientation/anchor changes.
- Invalid custom Deck Import now uses the existing PvP top utility-modal layer, blocks Deck Setup interaction while open, preserves the active deck, and resets the file input so the same invalid file can be selected again immediately.
- No gameplay semantics changed. Custom Main Deck legality remains 50–60 inclusive. Website mirror target remains v1.40.
