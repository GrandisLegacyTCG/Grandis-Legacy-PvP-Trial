# Grandis Legacy PvP v3.80.12 — 2026-10-12

## Scope

This is a deliberately narrow Response-focus presentation patch on top of v3.80.11. No Mana Payment, lobby, idle, networking, or gameplay-rule behavior is redesigned.

- During an Attack Response Window, the **entire attacker Hero lane box** stays above the response dim layer.
- The **entire current-target Hero lane box** stays above the response dim layer.
- Unrelated Hero lane boxes remain locally dimmed.
- Existing legal Response ability carve-out behavior is preserved.
- Zone targets continue to use the existing zone focus behavior.
